# athlete_career_dashboard

Athlete career dashboard with results, world ranking and progression information.

**Live page:** https://katrina-sutherland.github.io/athlete_career_dashboard/

## Summary

This dashboard follows Timothy ANDERSON’s MK1 career across world ranking and race experience.

- **Toggle between World Ranking and Race Experience** at the top of the page.
- Under **Race Experience**, switch between:
  - **Races by Age** — how many races he did each year of age, with race type breakdown and world ranking overlaid.
  - **Cumulative Races** — career race count building over time, with world ranking overlaid.
- On **Races by Age**, **Career Milestones** appear below the chart (first races, ranking bands, first semi/final/medal, and so on), each tied to the age they were reached.
- On **Cumulative Races**, click an age on the **Athlete Age** axis to see a summary tile for each competition that year — overall rank, and time as a % of the heat / semi / final winner.
